# Paper-To-Code Map

This document explains how the manuscript maps onto the files in this
repository. It is intended for readers who arrive from the paper and want to
know which code implements each scientific step.

## Manuscript

Title:

```text
Making the most from abrupt and sparse data:
Data driven interpolation from sporadic sensors of contaminant concentration
with extreme spatial gradients in saturated porous media
```

Authors:

```text
Alon Feldman, Shai Kendler, Yaniv Edery, Barak Fishbain
```

## Methods: Problem Formulation

Paper idea:

```text
f : Omega -> R
z = sparse measurements of f
d : R^s -> F
f_hat = d(z)
```

Code:

```text
code/preprocessing/extractSensorMeasurements.m
code/reconstruction/trainLinearRsimDecoder.m
code/reconstruction/predictLinearRsimDecoder.m
```

Notes:

- `extractSensorMeasurements` implements the encoding step from dense field to
  sparse sensor vector.
- `trainLinearRsimDecoder` learns the decoder from sparse vectors to dense
  fields.
- `predictLinearRsimDecoder` applies the learned decoder to held-out samples.

## Methods: System Overview

Paper idea:

```text
simulated dense fields -> sparse sensors -> decoder -> reconstructed field
```

Code:

```text
scripts/run_demo.m
scripts/run_training.m
code/config/defaultRsimConfig.m
```

Notes:

- `run_demo.m` is the recommended first entry point.
- `run_training.m` is the corresponding script for a larger copied dataset.
- `defaultRsimConfig.m` centralizes the standard experimental parameters.

## Sensor Placement Strategy

Paper idea:

Sensor locations are selected using local Shannon entropy over the simulated
ensemble, with minimum horizontal and vertical spacing constraints.

Code:

```text
code/sensor_placement/computeEntropyMap.m
code/sensor_placement/localShannonEntropy.m
code/sensor_placement/selectSensorsEntropy.m
```

Configuration:

```text
cfg.sensorCount = 30
cfg.minRowSeparation = 20
cfg.minColSeparation = 20
cfg.entropyBins = 64
```

Notes:

- The demo loads the stored 30 research sensor locations when available.
- The entropy functions are still used to visualize the information map and to
  support new sensor-count experiments.

## Model Specification

Paper model:

```text
f_hat(omega) = <W_omega, z> + b_omega
```

Publication-facing code:

```text
code/reconstruction/trainLinearRsimDecoder.m
code/reconstruction/predictLinearRsimDecoder.m
```

Legacy/original model path:

```text
legacy/original_matlab/linear_iterpolation.m
code/reconstruction/trainDenseNetworkDecoder.m
```

Important note:

The paper writes the linear model with a bias term. The original dense-network
MATLAB script initialized the fully-connected bias to zero and used
`BiasLearnRateFactor = 0`, so the default configuration sets
`cfg.useBias = false` to preserve the original computational behavior. Set
`cfg.useBias = true` only if the final experiment definition should learn an
intercept term.

## Classical Interpolation Baselines

Paper baselines:

```text

Nearest Neighbor

```

Code:

```text
scripts/run_compare_interpolation.m

```

Notes:

- The publication demo compares Linear, Natural, Nearest, IDW, and RSIM.
- The legacy scripts preserve the optional PyKrige calls for Ordinary and
  Universal Kriging.
- Cubic interpolation is mentioned in the manuscript but was not present in the
  active refactored comparison function; add it only after checking the exact
  original experiment behavior.
